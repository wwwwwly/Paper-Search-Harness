# 分析种子论文的问题、机制差异与双边证据

先确认种子身份和目标问题，再定向读取核心机制。共享主题不等于共享研究问题。对每个种子关系记录 shared_problem、different_mechanism/complementary/same_method/unclear。共享问题和差异陈述同时引用种子和候选的原始证据；摘要不足时按缺口读正文。只选择真正解决相同问题且方法不同或互补的工作。

下一步先明确缺口、预期收益与停止条件。使用 update_task、record_findings 和 submit_research 的当前版本语义。

具体例子按需读取 references/examples.md。
